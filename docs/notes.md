# Notes: pokemon-global-link

- Written from scratch for OpenPak; no third-party code. The unlicensed community GTS servers
  (ir-gts, RubyGTS) were not copied, only the publicly observable protocol is documented.
- SQLite, one writer: the traffic of a private network does not need Postgres.
- One open or uncollected GTS Pokemon per trainer per generation, as in the original.
